## 4. 顺序：决策与执行交替，不是全定完再动手

```text
阶段 0（无决策）      S0 清理与护栏            ← 立刻降风险，且不依赖任何决策
阶段 1（2 项决策）    D2 + D4 → S0.5 单设备单子表 → S1 契约与类型 → S3 模型定义
阶段 2（1 项决策）    D3 → S2 档案与状态机 → S4 注册路径
阶段 3（1 项决策）    D1 → S5 消费与降采样接线
阶段 4（1 项决策）    D5 → S6 边界口径 + S0 的孤儿清理落地
阶段 5               S7 验收
```

**同步点**（每 ≤3 个子任务停一次，≤30 分钟）：S0 后、S0.5 后、S3 后、S5 后、S7 前。每次只回答三件事：已完成 / 下一步 / 未决。

**为什么 D2 排第一**：它锁的是列名与列类型，一旦写入第一行数据就不可逆；而它同时决定 S4 的产物清单。

## 5. 超窗时的降级顺序

不按工时切，按"砍掉后判据是否还成立"切：

1. **S6 的报文上限与时间戳上界** → 只留位置与触发点（判据不依赖它）

**不砍**：判据 A/B/C 本身、D2 的两处不可逆（列名与列类型）、S0 的清理与审计。
