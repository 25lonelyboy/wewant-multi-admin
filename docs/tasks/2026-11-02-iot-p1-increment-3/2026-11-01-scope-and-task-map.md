## 4. 顺序：决策与执行交替，不是全定完再动手

```text
阶段 0（无决策）              S0 清理与护栏            ← 立刻降风险，且不依赖任何决策
阶段 1（D2 / D4）              S0.5 单设备单子表 → S1 契约与类型 → S3 模型定义
阶段 2（D3 已定）            S2 档案与状态机 → S4 注册路径
阶段 3（D1）                  S5 消费与降采样接线
阶段 4（D5 的注销与清理口径）    S6 边界口径 + S0 的孤儿清理落地
阶段 5                        S7 验收
```

**同步点**（每 ≤3 个子任务停一次，≤30 分钟）：S0 后、S0.5 后、S3 后、S5 后、S7 前。每次只回答三件事：已完成 / 下一步 / 未决。

**为什么 D2 排第一**：它锁的是列名与列类型，一旦写入第一行数据就不可逆；而它同时决定 S4 的产物清单。
