# 增量 3 · backlog 分诊

- **范围**：`docs/governance/backlog.md` 开放表全部 70 项（2026-11-01 版本）
- **判据**：只用一条——**本增量会不会让它更贵 / 本增量是不是已经踩到它**。附「顺手做」一档：低成本、与本次改动同一片代码
- **不看**：与 iot 链路无关的 40 余项（system 域、CI、文档治理、pure-web）——它们不在本增量判定范围

## A. 本增量必须处理（判据、接缝或被改动路径牵连）

| backlog 项 | 原文触发条件 | 本增量处置 | 归属 |
| --- | --- | --- | --- |
| 设备档案数据源过渡 | 增量 3 立项时实现 PG 档案 | 档案落 PG；设备两态 `PENDING/ACTIVE`，版本三态 `PENDING/ACTIVE/SUPERSEDED`（注册失败不落库，没有失败态）；`DeviceRegistry` 接口不变 | D1 / D3 |
| 设备类型注册 → 建超表无流程归属 | 增量 3 立项时 | 注册路径统一产出：档案 + 模型 + 超表 + 子表（1+3）+ 降采样列 | D3 |
| 契约 `value` 不支持非数值测点 | 增量 3 定义测点类型时 | `value` 改联合类型（number / boolean / string），类型由模型声明 | D2 |
| 设备档案缺协议版本字段 | 增量 3 设备注册落地 | 档案表加字段，来源是订阅端可见的 `proto_ver` | D1 |
| 标准单位换算时机（写时 vs 读时） | 已定 | **写时不转换**：载荷单位与模型声明不符即拒绝；展示单位在读时换算。口径收成一处（模型声明） | D2 §10 |
| 窗口内单位变更无护栏 | 已定 | 单位在模型内不可变 ⇒ 不存在窗口内换单位，无需运行时护栏 | D2 §10 |
| 测点列类型分档清单复核 | 增量 3 定型时用真实指标清单过一遍 | **列类型写第一行前定死**；用"运行状态 / 产量 / 良率 / 能耗 / 节拍"做纸面推演 | D2 |
| 子表只增不减（增量 2 记 12,353 张，来源未核实；本机核验为 100 / 300） | 设备注销流程落地时 | 只读审计（表存在 ⇔ 已注册）+ 开发环境重建库；正式删除随注销流程 | D5 |
| 批内同键不同值的行为 | 增量 3 物模型定型时 | 定一句口径：`(子表, ts)` 保留最后一条是幂等语义；是否需要告警由决策定 | D5 |
| `flushChain` 无失败分支 | 向 `flushOnce` 前置段新增可能抛错的改动时 | ⚠️ **本增量很可能命中**（模型查表/列映射可能落在前置段）——计划里必须先修，或明确把查表放在 try 内 | D3 |
| 降采样环对未登记原始子表整级失败 | 原始库出现未登记子表；**决策待定** | 与孤儿清理同源。二选一：读取侧按注册表裁剪，或只登记该失败模式 + 靠清理降概率 | D3 |

## B. 顺手做（低成本，与本次改动同一片）

| backlog 项 | 为什么顺手 | 成本 |
| --- | --- | --- |
| iot-worker e2e 写生产形态表且不清理 | e2e 残留正是子表债务的来源之一；清理时一起做才对得上账 | 两条用例加 `finally` 删除自己写入的 `ts` 区间 |
| 降采样对账脚本「空过」 | 本增量要立新判据；沿用会"0 组比 0 组还打绿"，与"判据要能红"直接冲突 | 两侧计数任一为 0 时不判过 |
| worker 无 healthcheck | 属"玩具 vs 产品"表里的显性缺口 | compose 加一个探针（worker 不开 HTTP，用进程/队列心跳） |
| 报文大小无上限 | 与物模型校验同层，都是"进队列之前挡一下" | 订阅端加一个字节上限（需定值） |
| 设备上报时间戳无边界 | detection 层本增量要改（读模型里的量程） | 加时钟偏差上界（需定值，如 ±24h，与阿里云口径同向） |

## 一句话结论

**A 档 11 项里，至少有 4 项是我上一版材料当成"约束"或"已定不必动"的**——契约 `value`、三测点全 `FLOAT`、单位随行落库（连带换算时机）、子表存量（当成迁移成本）。它们不是不能改，是没被算进来。B 档 5 项合计约半天，能把"子表债务"与"判据被骗"两个隐患一起按掉。

**收口时要做的一处 backlog 维护**：「测点集合未经效率指标倒推」的触发条件写的是"增量 3 立项前"，本增量给的是纸面推演而非重定。按维护规范（只追加或标注关闭），收口时把它关闭、把"P1 测点集合重定"作为新条目重新登记，触发点写"第一台真实设备接入前"。
