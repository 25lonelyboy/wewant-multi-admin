## 范围边界

本增量只做「订阅 + 可见性日志」：连上 EMQX、订阅设备主题、按日志规范记录收到的消息。

不做：不进队列、不落库（属增量 2）、不做设备注册与物模型（属增量 3）、不做 ACL 与设备级凭据（依赖平台侧设备档案）。
